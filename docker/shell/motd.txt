  │ Helm Shell · Cloudflare Container · two-disk model  │
  ╰─────────────────────────────────────────────────────╯

  /workspace   ephemeral SSD (15 min idle sleep)
  /persist     R2-mounted FUSE (durable; when R2_* set)

  Built-ins:
    helm "..."           → conductor REPL
    helm-save            → snapshot /workspace → R2
    helm-load            → restore latest snapshot
    helm-fetch <key>     → pull a Files-tab file → /workspace
    helm-fetch --list    → list every file you've uploaded
    helm-fetch --search  → find files by substring
    helm --plan "..."    → describe without running

  Pre-installed: bash, git, curl, jq, vim, tmux, htop,
  node, python3, rclone, tini.
